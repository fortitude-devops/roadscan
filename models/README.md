# Локальные модели детекции

Положите сюда файл весов — `.onnx` (предпочтительно) или `.pt`. Сервис подхватит первый найденный файл автоматически, либо укажите путь явно в `.env`:

```
AI_PROVIDER=local
LOCAL_MODEL_PATH=models/road_damage.onnx
```

## Зачем локальная модель

| | Локальный детектор | Облачный VLM |
|---|---|---|
| Интернет | не нужен | обязателен |
| Квоты и «503 high demand» | не бывает | регулярно |
| Скорость | 50–200 мс | 2–8 секунд |
| Точность на дорожных дефектах | выше: обучен именно на них | ниже: общая модель |
| Текстовое объяснение | генерируется из геометрии | пишет сам |

Поэтому оптимальна связка: `AI_PROVIDER=local`, а облачный провайдер в `AI_PROVIDER_FALLBACKS`.

## Где взять веса

**CamThink Road Damage Detection** — специализированная модель под ровно те классы, что нужны в кейсе: pothole, longitudinal crack, transverse crack, alligator crack, edge. Скачайте ONNX с их сайта и положите в эту папку.

**Альтернативы с теми же классами RDD2022:**

- `rezzzq/yolo12s-road-damage-rdd2022` на Hugging Face — классы D00, D10, D20, D40, Repair, вход 640×640
- `oracl4/RoadDamageDetection` на GitHub — YOLOv8, обучен на Crowdsensing-based Road Damage Detection Challenge 2022
- Roboflow Universe по запросу `pothole` — много готовых наборов и экспортов

## Если веса в формате .pt

Работать будут, но потянут PyTorch — это около 2 ГБ и несколько минут установки. На хакатоне лучше один раз сконвертировать в ONNX:

```bash
pip install ultralytics
yolo export model=best.pt format=onnx imgsz=640
```

Получится `best.onnx` — положите его сюда и удалите `.pt`. ONNX работает на `onnxruntime` весом ~50 МБ, без PyTorch.

## Проверить скачанный файл

Не уверены, та ли модель скачалась? Запустите:

```
python check_model.py models\ваш_файл.pt
```

Скрипт покажет формат, классы, размер входа и скажет, подходит ли модель. Для `.pt` PyTorch не требуется.

## Классы

Сопоставление классов детектора с типами дефектов сервиса — в `app/providers/local_detector.py`, словарь `CLASS_MAP`. Поиск идёт по подстроке, поэтому одинаково понимаются и коды RDD (`D00`, `D40`), и текстовые имена (`pothole`, `longitudinal crack`).

Если ваша модель использует другие названия — допишите пару строк в `CLASS_MAP`. Имена классов сервис берёт из метаданных ONNX; если их там нет, задайте вручную:

```
LOCAL_CLASS_NAMES=D00,D10,D20,D40,Repair
```

## Настройка порогов

```
LOCAL_CONF=0.30          # порог уверенности; выше — меньше ложных срабатываний
LOCAL_IOU=0.45           # порог подавления дублей
LOCAL_INPUT_SIZE=640     # если модель обучалась на другом размере
```

Начните с `LOCAL_CONF=0.30`. Если детектор видит дефекты на ровной дороге — поднимайте до 0.45–0.55 и проверяйте пакетом:

```bash
python analyze_cli.py "demo_images/normal_*.jpg" --expect none
```
